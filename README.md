# Timepass Arena

A simple static Movies & Anime discovery website.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — search and content modal

## Publish for free with GitHub Pages
1. Create a GitHub account.
2. Create a new public repository named `timepass-arena`.
3. Upload these three website files to the repository.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` branch and `/ (root)`, then Save.
7. GitHub will provide a public website link.

Only upload, embed, or link movies/anime that you own or are legally authorized to distribute.
